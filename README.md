Sistema de Controle de Equipe

Projeto desenvolvido em Java como parte dos meus estudos em Sistemas de Informação.

Sobre o projeto

O Sistema de Controle de Equipe tem como objetivo organizar e facilitar o gerenciamento de informações de uma equipe.

Tecnologias utilizadas

* Java
* Programação Orientada a Objetos
* Git e GitHub
* IntelliJ IDEA

Como executar

1. Clone este repositório.
2. Abra o projeto no IntelliJ IDEA.
3. Configure o JDK compatível com o projeto.
4. Execute a classe principal.
